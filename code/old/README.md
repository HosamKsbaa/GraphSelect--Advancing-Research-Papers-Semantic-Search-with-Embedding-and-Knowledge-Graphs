# Archived Code & Legacy Assets

This directory contains archived legacy assets and previous workflow iterations preserved for historical reference (Requirement R1):

- `legacy_graphselect_v2/`: Original GraphSelect v2.4 (FastAPI port from Flutter).
- `e2e_selenium/`: Deprecated Selenium E2E test suite (superseded by Playwright in `code/e2e_playwright/`).
- `docs_v1/`: Early milestone documentation and diagrams.
- `scripts/`: Ad-hoc diagnostic and scratch scripts (`do_gap_analysis.py`, `dump_logs.ps1`, `test_gemini_key.py`, `test_open_folder.py`) previously located in `code/`.
- `backend_workflow_v1/`: Pre-v2 literature review workflow reference snapshot (research, planning, writing, analysis, export modules, models, and project tools).

Active development occurs cleanly in `code/backend/` and `code/frontend/`.
